# Calorie Calculator

## About the Project
Calorie Calculator is a simple web project that allows users to enter their personal information and select their activity level and weight goal to calculate their recommended daily calorie intake.

## Features
- **Gender Selection:** Choose between male and female.
- **Age Input:** Enter age between 1 and 120.
- **Weight Input:** Enter weight in kilograms.
- **Height Input:** Enter height in centimeters.
- **Activity Level:** Choose from five activity levels.
- **Weight Goal:** Select weight loss, weight maintenance, or weight gain.
- **Form Validation:** Required fields and input limits help prevent invalid entries.
- **Custom Styling:** A clean interface built with HTML and CSS.

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open the HTML file in your web browser.
4. Fill in the required information and click **Calculate**.

## Project Structure
- `index.html` — Contains the HTML form and CSS styling.
- `results.html` — Intended for displaying the calculation results.

## Learning Objectives
This project was created to practice:
- Structuring web pages with HTML.
- Styling forms and layouts with CSS.
- Using form inputs, radio buttons, and dropdown menus.
- Applying basic HTML form validation.

## Note
The provided HTML code implements the input form and submits the data to `results.html`. The calorie calculation logic and results page must be implemented separately for the calculator to produce actual results.
